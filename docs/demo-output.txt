 (02_deny.sql)
==============================================================================
Goal: Grant broadly, then subtract one table with DENY.
Goal: See that a later GRANT cannot undo a DENY, and that only REVOKE DENY can.

==============================================================================
Goal: Let a user read some columns of a table but not others.

  [setup] PASS GRANT SELECT (id, name) ON tutorial.employees TO tut_ann@'%';
  [setup] PASS GRANT SELECT ON tutorial.employees TO tut_bob@'%';
  [setup] PASS DENY SELECT (salary) ON tutorial.employees TO tut_bob@'%';
